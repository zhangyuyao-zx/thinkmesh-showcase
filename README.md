# ThinkMesh · 从一道题，到每一次进步。

面向高中数学、物理、化学与生物的 AI 学习伙伴。自然交流、读题讲题、练习复盘，以长期学习证据持续校准对学生和知识点学习情况的认识。

[查看产品展示](https://zhangyuyao-zx.github.io/thinkmesh-showcase/) · [体验说明](https://zhangyuyao-zx.github.io/thinkmesh-showcase/experience.html) · [正式网站](https://thinkmesh.cn/login)

## 在学习中持续了解

- 从当前题目、已有步骤和真正卡住的环节开始辅导。
- 用公式、函数图、几何与物理示意辅助理解。
- 从已有教材与真题中选择练习，支持提交、批改、复盘与继续。
- 日常交流和实际作答形成可追溯证据，保留帮助条件、原始来源与历史修订。
- 学情区分需要关注、正在改善、基本稳定与证据不足，不把没有证据写成已经掌握。
- 长期记住个人背景与讲题偏好，支持查看来源、纠正和撤回；各科知识点证据保留学科边界。
- 四科知识星图支持拖动缩放、知识点选择、沿关系跳转、横屏查看与横竖版 PNG 下载。“已探索”不等于“已掌握”；关系区分学习建议与资料明示。

## 访问与账号

主要入口固定为 **https://thinkmesh.cn/login**，不依赖 GitHub API 或 JavaScript。默认中国大陆手机号验证码登录；新号码验证后需确认创建账号。已有账号应先用原邮箱或账号、密码登录，再绑定手机号，以保留原学习记录。登录页也提供邮箱验证码与密码注册；邀请码方式保留兼容，不是正式网站新用户的必需步骤。

`experience.html` 的折叠区域保留原临时备用入口。`entry.json` 仍由原流程独立维护，未改写或停用；展开后 `script.js` 先读取 GitHub 当前配置，失败时读取静态副本，并保留 HTTPS、凭据及域名白名单校验。`ready` 只表示配置状态，不是实时健康检查。配置失败不影响正式入口。
